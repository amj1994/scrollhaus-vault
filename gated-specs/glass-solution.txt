Build a single-page site called **ai/SmartSolution** — a dark spatial-scrolling showcase
of four full-screen glass cards (Productivity, Flexibility, Unify Teams, Team Created).
Recreate it EXACTLY as specified: stack, file layout, colors, spacing, copy, and animation
timing are all intentional. Do not substitute, paraphrase, or "improve" anything.

## 1. Stack & project setup
- Vite + React 19 + TypeScript + Tailwind CSS v4 (via `@tailwindcss/vite`, no separate
  config file) + framer-motion for every animation.
- Page background `#0a0d15`. Body font stack: `--font-jakarta` ("Plus Jakarta Sans")
  for display/headline text, `--font-aeonik` (DM Sans Variable) for body/UI text.
- Files: `src/main.tsx`, `src/App.tsx` (renders `<SpatialScroll />`), `src/index.css`,
  `src/hooks/useIsMobile.ts`, `src/BlurFadeWords.tsx`, `src/SpatialScroll.tsx`,
  `src/sections/AnimatedNetworkLines.tsx`, `src/sections/Section1Productivity.tsx`,
  `src/sections/Section2.tsx` (Flexibility), `src/sections/Section3.tsx` (Unify Teams),
  `src/sections/Section4.tsx` (Team Created). `public/assets/` holds 63 image/SVG assets.

## 2. Navigation model — SpatialScroll.tsx
On desktop, a 200vw × 200vh `motion.div` (driven by two framer-motion `useMotionValue`s,
`x`/`y`) sits inside a 100vw × 100vh `overflow:hidden` viewport. The four sections are
absolutely positioned in a clockwise loop:
- Section 1: top 0, left 0
- Section 2: top 0, left 74vw
- Section 3: top 82vh, left 74vw
- Section 4: top 82vh, left 0
A non-passive `wheel` listener (deltaY > 0 = forward, < 0 = backward, blocked in reverse
until the loop has completed once) calls `animate(x, …)`/`animate(y, …)` with
`duration:0.85, ease:[0.76,0,0.24,1]`, followed by a 950ms re-trigger cooldown. Touch swipe
(50px threshold, dominant axis wins) drives the same `goTo`. On resize, position snaps to
the current section without re-animating. Below 1024px width, this collapses to a plain
vertical `overflowY:scroll` container with `scroll-snap-type:y mandatory` and each section
wrapped in a `scroll-snap-align:start` slot instead.

## 3. Shared card scaling wrapper (used identically by all 4 sections)
Each section is a native 1040×684px card, scaled to fit: `scale = min(1, w/1440, h/900)`
on desktop, or `max(0.28, (w-24)/1040)` on mobile. The card renders at native size inside
an absolutely-positioned `transform:scale(...)` wrapper so nothing reflows at odd sizes.
Each card: `borderRadius:24px`, `backgroundSize:115%`, `backgroundPosition:center`,
`overflow:hidden`, and a heavy multi-layer `boxShadow` for depth. Entrance animations are
gated behind an `IntersectionObserver` (92% visible to fire on desktop, 20% on mobile;
resets below 10%/5%) so each section replays its intro every time it's scrolled back into
view, not just once.

## 8. Shared components
- `BlurFadeWords`: splits text into words, each animates `opacity:0,blur(8px)` →
  `opacity:1,blur(0)`, delay `baseDelay + i*0.07`, duration 0.5s, easeOut.
- Local `AnimatedWords` (defined inside Sections 1 & 2 only): simpler word-by-word opacity
  fade, no blur, delay `baseDelay + i*0.1`, duration 0.4s.
- `MagicBorder`: a 2px conic-gradient ring masked to only show the border (WebkitMask xor
  trick), rotating infinitely — reused with a different accent color per section.
- `AnimatedNetworkLines`: 30 SVG paths draw in via `pathLength` animation staggered 0.1s
  apart; the first two paths also carry a glowing dot that travels the path on an
  `animateMotion` loop; a Gaussian-blurred colored "hub" glow fades in at the network's
  center.

## 9. Responsive behavior
Below 1024px, `SpatialScroll` switches to vertical scroll-snap and every section's
`IntersectionObserver` thresholds relax (20%/5% instead of 92%/10%) so content reveals
sooner on a slower swipe gesture. Card scale clamps to a minimum of 0.28 so the layout
never collapses to unreadable size on narrow phones.
