Build a single-page website called **TENTH HEATING & AIR** — a warm, literary emergency-
HVAC landing page told as a 145-frame scroll-scrubbed image sequence with GSAP
ScrollTrigger choreography. Recreate it EXACTLY as specified below: every color token,
class, easing curve, animation timing, and line of copy is intentional. Do not substitute,
paraphrase, or "improve" anything.

## 1. Stack & project setup
- Plain static HTML/CSS/JS. No build step, no bundler, no framework.
- One file: `index.html`. Must be served over HTTP (not opened via `file://`) because the
  frame sequence is loaded with `new Image()` from a relative `frames/` folder.
- One external dependency, both loaded from CDN in `<head>`:
  `https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js`
  `https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/ScrollTrigger.min.js`
- Fonts via Google Fonts `<link>`: Fraunces (opsz,wght axis: 9..144,300 / 9..144,500 /
  9..144,700 — display serif, used bold for the H1 and medium for section H2s), Public
  Sans (400/500/600, body), JetBrains Mono (400/500, all-caps labels and numeric readouts).
- `<title>The Third Time...` — no: title is `Tenth Name — Emergency Heat, Seven Days`
  (the literal title tag shipped in the source repo — reproduce it exactly, even though
  "Tenth Name" reads as an unfilled placeholder next to the polished brand mark "Tenth."
  used everywhere else on the page). `<link rel="icon" href="data:,">` (empty favicon,
  intentional).

## 2. Asset pipeline — the 145-frame sequence
- `frames/f_001.jpg` … `frames/f_145.jpg` (3-digit zero-padded index, `TOTAL = 145`,
  `PAD = 3`). Real photographic frames of a single continuous take/camera move — a
  pre-dawn HVAC emergency call at an elderly woman's house, resolving into a warm family
  breakfast scene by the final beats. Scrubbing through the sequence must read as one
  unbroken shot advancing forward, never a jump-cut or reversal.
- All 145 images preload with `new Image()` on page load, `decoding="async"`. A loader
  screen ("Reading service record" + a thin progress bar + percentage) tracks
  `loaded / TOTAL`, revealing the page once every frame has loaded (`onload`/`onerror`
  both count so one broken frame can't hang the loader). A 9-second hard timeout
  force-starts the page even if some frames never resolve.
- An optional `ASSET_BASE` global (empty string by default) can prefix every frame URL to
  serve frames from a CDN/origin in production instead of the bundled `frames/` folder —
  leave it unset to use the bundled frames.

## 4. Color system (CSS custom properties, oklch)
```
--cold:       oklch(0.205 0.032 192)  /* opening palette: oxidized copper / verdigris */
--warm:       oklch(0.245 0.048 52)   /* closing palette: raw copper */
--ink:        oklch(0.945 0.012 82)   /* primary text */
--muted:      oklch(0.735 0.021 192)  /* secondary/label text */
--copper:     oklch(0.735 0.132 56)   /* accent — active states, links, brand period */
--copper-dim: oklch(0.52 0.085 56)    /* declared but only used sparingly, keep the token */
--tag:        oklch(0.885 0.028 88)   /* the service-tag background */
--tag-ink:    oklch(0.30 0.035 60)    /* text on the tag */
--hair:       oklch(1 0 0 / 0.13)     /* hairline borders */
```
Body background is `--cold`. A fixed full-viewport pseudo-element (`body::before`) holds
`--warm` at `opacity: var(--heat)`, and `--heat` is driven live by scroll progress
(0 → 1 across the whole film) — the entire page's background temperature crossfades from
cold oxidized-copper/verdigris to warm raw-copper as the user scrolls through the call,
independent of whatever the current frame shows. This is the central visual mechanic and
must not be skipped or approximated. The header thermometer readout is driven by the same
progress value on a literal linear map: `41 + p * 27` (41°F at p=0, 68°F at p=1) — use
that exact formula, not a different curve.

## 6. Scroll mechanics — canvas frame scrub
- `progress()` reads `.film`'s bounding rect: `span = height - innerHeight`,
  `progress = clamp(-top / span, 0, 1)`.
- GSAP ScrollTrigger drives a plain object `{ i: 0 }` from 0 to `TOTAL - 1` with
  `ease: 'none'` and `scrub: 0.5` (`trigger: film, start: 'top top', end: 'bottom bottom'`),
  calling `paint(f.i)` on every update. `scrub: 0.5` gives the frame advance a slight
  trailing smoothness relative to raw scroll — do not use `scrub: true`/`0`.
- `paint(idx)`: rounds and clamps the index, skips redraw if it's the same frame already
  drawn, then manually letterboxes the image into the canvas (cover-fit math: compare
  image aspect ratio to canvas aspect ratio, draw at whichever dimension overflows,
  centered).
- `readout(p)`: sets `--heat` (drives the cold→warm background crossfade) and updates the
  header thermometer text and which rail tick is active, every frame, from scroll progress.
- Canvas resizes to its container on `resize` (DPR capped at 2), and ScrollTrigger is
  refreshed after.
- A `?at=0.62`-style query param jumps the scroll position to that fraction of the film on
  load (`window.filmScrub.jumpTo`), for deep-linking to a specific beat.

## 7. Scroll mechanics — copy choreography
For every hero/beat panel, a separate ScrollTrigger timeline (`trigger` = the parent
section, `start: 'top bottom'`, `end: 'bottom top'`, `scrub: 0.7`) runs:
1. Panel fades/rises in: `autoAlpha 0→1`, `y 26→0`, 0.55s, `power2.out`, at timeline start.
2. The `.temp` label slides in from the left (`x -14→0`) slightly after (offset 0.10).
3. Each word span rises in with a 0.045s stagger (`autoAlpha 0→1`, `y 20→0`, `power2.out`),
   offset 0.15.
4. A hold (`duration: 1.15`, no properties) so the fully-revealed state persists.
5. Words drift out (`autoAlpha 1→0`, `y -14`, 0.02s stagger) followed almost immediately
   by the whole panel fading/dropping out (`autoAlpha 1→0`, `y -22`).
Below the film, `.rev`-tagged elements (record heading/paragraph, the service tag) reveal
once on scroll-into-view (`start: 'top 86%'`/`'84%'`, `once: true`) with word-level or
block-level `gsap.from` — never re-triggered on scroll back up. The tag itself animates in
with a slight counter-rotation settle (`rotation: -2.6 → -1.1` implied by the base
transform), its list rows sliding in from the left with a 0.075s stagger, and the facts
list fading up with a 0.09s stagger.

**Documented failure mode to avoid** (shared with the sibling barbershop template): if an
element is skipped during a fast scroll rather than passing through every intermediate
scrollTrigger update, its opacity/transform must still be explicitly written on the skip
path — otherwise it freezes at its last computed value instead of reaching its target
state.

## 8. Accessibility — `prefers-reduced-motion: reduce`
Hard requirement with a CSS `!important` backstop in addition to the JS branch:
- CSS: all animations/transitions collapse to `0.01ms`, `.stage` becomes
  `position: relative; height: 70svh` (unpins from sticky), `.film` height reverts to
  `auto`, `.beats` loses its negative margin, beat sections get normal padding instead of
  full-height flex centering, the scroll-cue underline animation stops, and every
  word/reveal/tag-row/fact/panel/temp-label element is forced to
  `opacity: 1 !important; transform: none !important; visibility: visible !important` —
  everything visible, nothing animated.
- JS: `layout()` sets the film height to `auto` (skipping the `520vh` scroll-driven track)
  when `matchMedia('(prefers-reduced-motion: reduce)').matches`, and the GSAP `matchMedia`
  reduced-motion branch simply paints frame 0 and calls `readout(0)` once instead of
  building any ScrollTrigger timeline.
