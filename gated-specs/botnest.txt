Build "BotNest" — a dark, lime-accented AI-agent SaaS landing page. Vite + React 18 +
TypeScript + Tailwind CSS. Nineteen sections, each revealed by its own IntersectionObserver
(no scroll-scrubbed video on this page — the motion is all opacity/translate reveals plus a
handful of self-driving animations). No external image or video assets: every visual is CSS,
inline SVG and lucide-react icons.

===============================================================================
STACK & FILES
===============================================================================
Vite + React + TypeScript + Tailwind (default config, no theme extension besides two font
vars). Path alias '@' -> './src'. Dependencies: framer-motion, lucide-react, clsx,

RECURRING PATTERNS — implement once, reuse everywhere
===============================================================================
REVEAL-ON-SCROLL: nearly every section component follows the identical shape —
  const ref = useRef<HTMLDivElement>(null); const [visible, setVisible] = useState(false);
  useEffect(() => {
    const el = ref.current; if (!el) return;
    const observer = new IntersectionObserver((entries) => entries.forEach(e => {
      if (e.isIntersecting) { setVisible(true); observer.unobserve(e.target) }
    }), { threshold: 0.15 });   // 0.1-0.3 depending on section, see below
    observer.observe(el);
    return () => observer.disconnect();
  }, []);
Then each child in the section transitions opacity 0->1 and translateY/X 20-24px->0 over
600-1000ms, staggered with transitionDelay: `${index * N}ms` (N is 80-150ms depending on
section — see per-section notes). This fires once, on first intersection, and never resets.

AGENT-ORB icon treatment (AgentCards.css): a 56x56 rounded-2xl box (smaller 40/48px variants
elsewhere) with a ::before layer at inset:0 carrying a 135deg gradient from --accent-dim to
transparent at 60%, opacity .6 — a soft interior glow behind the lucide icon. Reused as
"agent-orb" across AgentCards, FeatureSection, FeatureShowcaseSection, PostLaunchSection,
StressTestScenariosSection, TestimonialMetricsSection, ParallaxHero and TrackWhatMattersSection
at different sizes via w-*/h-*/rounded-* overrides.

METRIC BAR: .agent-metric-bar{height:4px;border-radius:2px;background:var(--bg-elevated);
overflow:hidden} .agent-metric-bar-fill{height:100%;border-radius:2px;
background:linear-gradient(90deg,var(--accent),var(--accent-hover));
transition:width 1s cubic-bezier(.4,0,.2,1)} — width goes from 0% to the metric value only
once `visible` flips true, so the bar animates in.

GLASS PILL EYEBROW: every section opens with the same eyebrow badge —

  <Icon className="w-3.5 h-3.5 text-[var(--accent)]" />

</div>

action.", sub "From live conversations to test results to analytics — all running on the

THIS IS THE ONE SELF-ANIMATING SECTION ON THE PAGE — it auto-advances independent of scroll,
so it is worth lingering on in any preview capture. A .demo-window (max-w-3xl, rounded-xl,
bg-secondary, 1px border) with a macOS titlebar (three colored dots, then three tab buttons
— Live Chat/MessageSquare, Test Suite/FlaskConical, Analytics/BarChart3 — the active tab gets
bg-card text-primary, others text-tertiary). Below, a 16:10 .experience-frame containing
three absolutely-stacked .experience-screen layers that cross-fade via opacity (only .active
shows), plus a 2px .experience-progress bar along the bottom edge that fills 0->100% width
over the current screen's dwell.

Auto-advance: a setInterval every 40ms increments progress by 0.5 (so ~4s per screen); at
100 it resets progress to 0 and advances `active` to the next screen in sequence
(chat -> testing -> analytics -> chat...). Clicking a tab jumps directly to that screen and
resets progress. Below the frame: three small dot buttons (.experience-nav-dot, active one
widens to 24px pill), same jump behavior.

ChatScreen: four alternating chat bubbles (user right-aligned accent bg, bot left-aligned
bg-elevated), each fading/rising in via .chat-bubble-in (opacity 0->1, translateY(8px)->0,
staggered 150ms), plus a trailing bot "typing" bubble with three bouncing dots
(.typing-dots, staggered 0/0.2s/0.4s, translateY(-4px) bounce). Messages:
  user: "I need to reschedule my appointment to next week"
  bot: "Sure! I can see you're booked for Thursday at 2pm. Would Tuesday or Wednesday next
    week work?"
  user: "Wednesday morning if possible"
  bot: "Got it — Wednesday at 9:30am is available. Should I confirm that for you?"

TestingScreen: header row "echo/test_run_8421" (mono) + "5 pass · 1 warn" (accent mono).
Six test rows, each a status dot (accent=pass, warm=warn) + name + time, fading in staggered
100ms: Greeting flow 0.3s pass, Escalation path 0.5s pass, Ambiguous intent 0.8s pass,

ACCEPTANCE
===============================================================================
- No third-party image or video URLs anywhere — only the Google Fonts stylesheet and one
  inline data-URI SVG noise texture. Nothing to swap or re-host.
- Every section fires its IntersectionObserver reveal exactly once and never resets on
  scroll-back.
- The ExperienceSection demo auto-advances chat -> testing -> analytics on a ~4s cycle
  independent of scroll position, and clicking a tab or dot jumps immediately and resets
  the progress bar.
- AgentCards tilt in 3D on hover (rotateY/rotateX via agent-card-inner's
  transform-style:preserve-3d) — this is a real perspective transform, not a flat scale.
- Mobile agent carousel responds to a horizontal swipe of more than 40px; tapping a dot
  jumps directly to that agent.
- Header background/border only appear after 20px of scroll; before that it's transparent
  over the hero.
- Zero console errors; zero external network requests besides the Google Fonts stylesheet.
