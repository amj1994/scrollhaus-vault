logo.glb - the header monogram "LE". One material, Chrome_rough_optimised: metallicFactor 1.0, baseColorFactor 0.8/0.8/0.8, and a metallicRoughnessTexture EMBEDDED inside the glb. That embedded texture is what makes it read as polished chrome; roughnessFactor on its own is 1.0, which would render a dull matte metal. The model is authored UPSIDE DOWN - the code applies geo.rotateX(Math.PI) to stand it up. It is a single merged mesh with no named top/bottom halves, so the code cuts the geometry in half by triangle-centroid Y at load time; the two halves then spin at different lerp rates, which is the whole point of the effect. NOT Draco compressed.

copyright.glb - the 3D copyright mark in the footer. Same Chrome_rough_optimised material with the same embedded roughness texture. NOT Draco compressed.

Neither glb uses Draco. Do not wire up a DRACOLoader; it is dead weight.

env.webp - 2048x1024 equirectangular environment map. Load it with THREE.TextureLoader, set mapping = THREE.EquirectangularReflectionMapping and colorSpace = THREE.SRGBColorSpace, run it through PMREMGenerator, and assign the result to scene.environment. This single texture drives the chrome reflections on BOTH models. It is the only standalone texture in the project; everything else is embedded or drawn in CSS.

elevator.mp4 - 1280x1238, h264, 24 fps, 114 frames, 4.75 seconds. Every single frame is a keyframe (encoded with keyint=1:min-keyint=1:scenecut=0) plus faststart, so seeking is instant. This matters: the video is not played, it is scrubbed frame-by-frame by scroll position. A normally-encoded video with a standard GOP will stutter badly.

pic1..pic6.jpg - the six gallery images, used in that order by the cards .pg-item-1 through .pg-item-6.


NON-OBVIOUS REQUIREMENTS

These are the things that look fine in code review and then break at runtime. Every one of them was found by measuring the live page, not by reading it.

0. THE PAGE SCROLLS ON THE WINDOW. Read this one twice; it is the single most likely way to end up with a page that renders perfectly and does not scroll at all.

Lenis and every ScrollTrigger in this project are bound to the window. If your app shell wraps the content in an element that owns the scroll - the default React/Vite/Next scaffold does exactly this with `#root { height: 100vh; overflow-y: auto }`, and so does any `html, body { height: 100%; overflow: hidden }` - then the document collapses to a single viewport, window.scrollY never changes, no ScrollTrigger ever fires and the page is frozen. Nothing throws. The console stays clean. It just does not move.

Do not wrap this page in a scrolling container. Render it directly into the body. The stylesheet already contains defensive rules that neutralise a scaffold that does it anyway:

  html, body { height: auto !important; }
  html:not(.lenis-stopped) { overflow: visible !important; }
  #root, #__next, #app { height: auto !important; min-height: 0 !important; overflow: visible !important; }

Keep those rules. Do not "clean them up".

0b. Ship Lenis' own stylesheet, which is in the code below. Lenis only toggles class names on <html>; every behaviour behind those names lives in CSS you must provide:

  html.lenis, html.lenis body { height: auto; }
  .lenis.lenis-smooth { scroll-behavior: auto !important; }
  .lenis.lenis-smooth [data-lenis-prevent] { overscroll-behavior: contain; }
  .lenis.lenis-stopped { overflow: hidden !important; }
  .lenis.lenis-smooth iframe { pointer-events: none; }

Without `.lenis-stopped { overflow: hidden }` the lenis.stop() that the menu calls on open blocks the mouse wheel but not the scrollbar, the arrow keys, or touch - the page keeps scrolling behind the open panel. Without `scroll-behavior: auto` a host stylesheet that sets `scroll-behavior: smooth` on html (Tailwind and shadcn starters commonly do) fights Lenis for control of every frame.

Note that `.lenis-stopped` hides the root scrollbar while the menu is open. On a platform with classic, space-taking scrollbars that reflows the page by about 15px at the moment the menu opens. This is upstream Lenis behaviour. If it bothers you, add `scrollbar-gutter: stable` to html - at the cost of permanently reserving that gutter.

0c. Do not reintroduce CSS custom properties for the text colours. The glitch section is the only thing that makes its own text white: `.section.glitch { color: #fff }`, inherited four levels down to the scrambling characters, while `body { color: #000 }`. Both used to read `var(--white)` and `var(--black)` from a :root block that came out of a Webflow export carrying two unparsable property names. A browser tolerates that and drops only the bad declarations; a CSS build pipeline drops the whole :root. Then --white no longer exists, `color: var(--white)` is invalid at computed-value time, the property falls back to inherit, body's colour is equally broken, and every character of "we are premium" renders black on a dark elevator. Nothing errors. Both colours are now hard-coded literals and :root is gone from the base stylesheet. Keep them literal.

1. The video must be served over HTTP Range (206 Partial Content). If the host answers 200 to a Range request, video.seekable is empty, currentTime silently refuses to move, and the scrub sticks at frame 0 forever with no error in the console. The hosting above already answers 206.

2. The video element MUST carry an explicit CSS aspect-ratio of 1280 / 1238. Do not set width/height HTML attributes instead - CSS width:100% overrides the width attribute but the height attribute survives as a presentational hint, which pins a wrong fixed height and letterboxes the video. With no intrinsic ratio at all, Chrome lays a <video> out at its default 300x150 until metadata arrives, so the glitch section collapses from about 1462px tall to 150px, the gallery below is yanked up into the hero, its scroll-triggered reveal fires there because its start point is already passed, and everything then drops back down when the 8 MB file finally lands. The user sees the gallery heading flash in the hero and slide away.

3. Set history.scrollRestoration = 'manual' in an early inline script in the head, and scroll to 0 on beforeunload. This page is scroll-driven; a restored scroll offset drops the visitor into the middle of an animation whose entry trigger has already passed.

4. Never take a shortcut in the masked-reveal initialiser. The reveal init is lazy (IntersectionObserver plus requestIdleCallback), so on a slow load or a fast flick it can run when its section is already on screen. If you handle that case by snapping the words visible and returning early, no ScrollTrigger is ever created and the reveal can never play, not even after scrolling back up. Always create the ScrollTrigger; it fires onEnter by itself when its start point has already been passed.

5. The header logo and the footer copyright spin from scroll velocity and snap when scrolling stops. The snap quantum is a FULL turn, 2*PI, not a half turn. The effect this is derived from snaps to PI, which is fine for a mirror-symmetric mark but leaves this monogram resting back-to-front half of the time. Use const TURN = Math.PI * 2 and quantise ceil/floor/round by TURN.

6. The gallery heading is position:sticky and its section is pulled up with margin-top:-70vh, so a ScrollTrigger anchored on the heading evaluates as already-started at load and fires off-screen. Anchor the reveal on the non-sticky .s3-gallery-section instead, with start: 'top 30%'.

7. The gallery section must have background: transparent and its ::before disabled. An opaque black background there covers the elevator video's own fade-to-black and destroys the transition between the two sections.

8. Do not give .glitch-text-w a position or z-index. It relies on its inherited position:absolute; setting relative or a stacking context breaks the layout of the whole glitch section. The dark scrim over the video is .glitch-img-w::after with NO z-index - it paints under .glitch-text-w purely by DOM order.

9. In the mobile stylesheet, the header nav columns are hidden with the selector `.lf-header .col`, not `.lf-c1, .lf-c2, .lf-c3, .lf-c4`. The base rule `.lf-header .col { display: flex }` has specificity 0-2-0 and will beat a bare class selector at 0-1-0 no matter what media query wraps it. Get this wrong and the nav stays on screen on phones and shoves the MENU button off the right edge.

10. Every `<br class="lf-br">` has a real space in front of it in the markup. Those breaks are display:none below 1025px, and without the space the words on either side fuse: "the prompt,and ship", "looks likea studio".

11. The rule that shrinks the sticky gallery heading on small screens must be written AFTER the rule that sets its desktop `height: 60vh`. The source stylesheet gives it `min-height: 70vh` below 768px; an identical override placed earlier in the file loses on source order, not on specificity or media.

12. The footer's 3D copyright block is position:absolute on desktop, straddling the footer's bottom edge. Below 1025px it becomes a static centred block, and the empty right-hand panel that props the desktop grid open is hidden - otherwise it stacks under the links and punches a 191px hole.


KNOWN QUIRK, INHERITED FROM THE SOURCE

Below 480px the stylesheet sets `.section.glitch { overflow: visible }` (its base value is `overflow: clip`). During the glitch, a single scrambled letter drifts about 4px past the right edge and the page gains a 4px horizontal scroll for a moment. To reproduce the original exactly, keep `overflow: visible`. To ship it clean, replace that one rule with `overflow-x: clip; overflow-y: visible` - clip, unlike hidden, does not create a scroll container and does not break the sticky elements inside.

const CHARS = 'abcdefghijklmnopqrstuvwxyzABCDEFGHJKMNPQRSTUVWXYZ0123456789#$()!?"§&<>@*+-'; // sx
const WINDOW = 22;      // ox — how many chars the scramble wave spans
const FRAME_MOD = 8;    // uC — scramble updates every N animation frames
const FINAL_WINDOW = 4; // fC — scramble edge width of the final-text reveal

/* ax — split an element's text into per-character inline-block spans. */
function splitChars(root) {
  const out = [];
  function walk(node) {
    if (node.nodeType === Node.TEXT_NODE) {
      const frag = document.createDocumentFragment();
      for (const ch of node.textContent) {
        if (ch === ' ' || ch === ' ' || ch === '\n') {
          frag.appendChild(document.createTextNode(ch));
        } else {
          const span = document.createElement('span');
          span.style.display = 'inline-block';
          span.textContent = ch;
          frag.appendChild(span);
          out.push({ span, original: ch });
        }
      }
      node.parentNode.replaceChild(frag, node);
    } else if (node.nodeType === Node.ELEMENT_NODE) {
      [...node.childNodes].forEach(walk);
    }
  }
  [...root.childNodes].forEach(walk);
  return out;
}

/* lx — one random glitch character. */
function randChar() {
  return CHARS[Math.floor(Math.random() * CHARS.length)];
}

/* hC — scramble a block: a WINDOW-wide wave starting at `head`, strength `intensity`. */
function scrambleBlock(chars, head, intensity) {
  const n = chars.length;
  if (!n) return;
  const i = ((Math.floor(head) % n) + n) % n;
  chars.forEach(({ span, original }, a) => {
    let c = a - i;
    if (c < 0) c += n;
    if (c < WINDOW) {
      const l = intensity * Math.pow(1 - c / WINDOW, 0.6);
      span.textContent = Math.random() < l ? randChar() : original;
    } else {
      span.textContent = original;
    }
  });
}

/* dC — reveal the final sentence progressively, scrambled at its leading edge. */
function revealFinal(chars, progress) {
  if (!chars.length) return;
  const t = progress * chars.length;
  chars.forEach(({ span, original }, s) => {
    if (s < t - FINAL_WINDOW) {
      span.style.opacity = '1';
      span.textContent = original;
    } else if (s < t) {
      span.style.opacity = '1';
      span.textContent = randChar();
    } else {
      span.style.opacity = '0';
      span.textContent = original;
    }
  });
}

/* cx — wire up every .section.glitch. */
function setupGlitch() {
  document.querySelectorAll('.section.glitch').forEach((section) => {
    const blocks = [...section.querySelectorAll('.text-block-6')];
    if (!blocks.length) return;

    const blockChars = blocks.map(splitChars);                       // i
    const allChars = blockChars.flat();                              // s
    const maxLen = Math.max(...blockChars.map((c) => c.length), 1);  // o

    const finalEl = section.querySelector('.finaltext');
    const finalChars = finalEl ? splitChars(finalEl) : [];           // l
    finalChars.forEach(({ span }) => { span.style.opacity = '0'; });

    let smooth = 0, target = 0, head = 0, raf = null;
    let running = false, frame = 0, fallTL = null, lastProg = -1;

    function tick() {
      if (!running) return;
      frame++;
      smooth += (target - smooth) * 0.14;
      target *= 0.9;
      if (frame % FRAME_MOD === 0) {
        if (smooth > 0.01) {
          head = (head + 1 + smooth * 10) % maxLen;
          blockChars.forEach((c) => scrambleBlock(c, head, smooth));
        } else {
          allChars.forEach(({ span, original }) => { span.textContent = original; });
        }
        if (finalChars.length && fallTL) {
          const w = fallTL.scrollTrigger ? fallTL.scrollTrigger.progress : 0;
          if (Math.abs(w - lastProg) > 2e-4) {
            revealFinal(finalChars, w);
          } else {
            const L = w * finalChars.length;
            finalChars.forEach(({ span, original }, I) => {
              span.style.opacity = I < L ? '1' : '0';
              span.textContent = original;
            });
          }
          lastProg = w;
        }
      }
      raf = requestAnimationFrame(tick);
    }

    function start() {
      if (running) return;
      running = true; frame = 0;
      raf = requestAnimationFrame(tick);
    }
    function stop() {
      running = false; target = 0; smooth = 0;
      if (raf) { cancelAnimationFrame(raf); raf = null; }
      allChars.forEach(({ span, original }) => { span.textContent = original; });
      finalChars.forEach(({ span, original }) => { span.style.opacity = '0'; span.textContent = original; });
      lastProg = -1;
    }

    /* Scramble driver: intensity from scroll velocity while the section is in view. */
    ScrollTrigger.create({
      trigger: section, start: 'top bottom', end: 'bottom top',
      onEnter: start, onLeave: stop, onEnterBack: start, onLeaveBack: stop,
      onUpdate(self) {
        const v = Math.abs(self.getVelocity());
        target = Math.min(v / 3400, 0.45);
      },
    });

    /* Scrubbed fall: each character drops / rotates / fades as you scroll in. */
    fallTL = gsap.timeline({
      scrollTrigger: { trigger: section, start: 'top top', end: 'center 30%', scrub: 2 },
    });
    blockChars.forEach((chars, idx) => {
      const base = idx * 0.06;
      chars.forEach(({ span }) => {
        fallTL.to(span, {
          y: gsap.utils.random(40, 160),
          x: gsap.utils.random(-10, 10),
          rotation: gsap.utils.random(-20, 20),
          opacity: 0,
          ease: 'power2.in',
          duration: gsap.utils.random(0.25, 0.7),
        }, base + gsap.utils.random(0, 0.6));
      });
    });

    /* Elevator media: the original image was dimmed to 0.3 while scrolling; now that it is a
       scroll-scrubbed VIDEO we keep it fully visible so the playback reads. (Fade removed.) */

    /* Elevator VIDEO scrubbed by scroll: currentTime is driven by the section's scroll
       progress (top-bottom → bottom-top), so the clip plays as you scroll through. */
    const elevatorVid = section.querySelector('video.img-ascenseur');
    if (elevatorVid) {
      elevatorVid.pause();
      const scrubVideo = () => {
        gsap.to(elevatorVid, {
          currentTime: elevatorVid.duration || 0,
          ease: 'none',
          scrollTrigger: { trigger: section, start: 'top bottom', end: 'bottom top', scrub: 1 },
        });
        ScrollTrigger.refresh();
      };
      if (elevatorVid.readyState >= 1) scrubVideo();
      else elevatorVid.addEventListener('loadedmetadata', scrubVideo, { once: true });
    }

    /* merguez + ballon block parallax. */
    const imgGlitchW = section.querySelector('.img-glitch-w');
    if (imgGlitchW) {
      const [m, b] = [...imgGlitchW.children];
      if (m) gsap.fromTo(m, { y: 100 }, { y: -300, ease: 'none',
        scrollTrigger: { trigger: section, start: 'top top', end: 'bottom top', scrub: 1.5 } });
      if (b) gsap.fromTo(b, { y: 100 }, { y: -800, ease: 'none',
        scrollTrigger: { trigger: section, start: 'top top', end: 'bottom top', scrub: 3 } });
    }

    /* Inner-image parallax inside merguez / ballon frames. */
    [
      { wrap: '.merguez', img: '.merguez-img', yPct: -8 },
      { wrap: '.ballon',  img: '.ballon-img',  yPct: 10 },
    ].forEach(({ wrap, img, yPct }) => {
      const W = section.querySelector(wrap), I = section.querySelector(img);
      if (!W || !I) return;
      gsap.set(W, { overflow: 'hidden' });
      gsap.set(I, { height: '110%', width: '100%', objectFit: 'cover', top: 0 });
      gsap.fromTo(I, { yPercent: 0 }, { yPercent: yPct, ease: 'none',
        scrollTrigger: { trigger: section, start: '20% top', end: 'bottom top', scrub: 3 } });
    });
  });
}

/* Split an indexed/non-indexed geometry into top/bottom halves by triangle-centroid Y
   (both halves keep the SAME origin so they spin around one shared vertical axis — as in
   the source effect, where top/bottom desync while scrolling then snap back together). */
function splitByY(geo) {
  const pos = geo.attributes.position, idx = geo.index;
  const triCount = idx ? idx.count / 3 : pos.count / 3;
  const topI = [], botI = [];
  for (let t = 0; t < triCount; t++) {
    const a = idx ? idx.getX(t * 3)     : t * 3;
    const b = idx ? idx.getX(t * 3 + 1) : t * 3 + 1;
    const c = idx ? idx.getX(t * 3 + 2) : t * 3 + 2;
    const y = (pos.getY(a) + pos.getY(b) + pos.getY(c)) / 3;
    (y >= 0 ? topI : botI).push(a, b, c);
  }
  const mk = (arr) => { const g = geo.clone(); g.setIndex(arr); return g; };
  return { topGeo: mk(topI), botGeo: mk(botI) };
}

function set2D() {
  if (logo.state === '2D') return;
  logo.state = '2D'; logo.mouseFactor = 0;
  gsap.to(logo, { mouseInfluence: 0, duration: 1, ease: 'expo.out' });
  gsap.to(logo.base.scale, { z: 1, duration: 0.75, ease: 'expo.out' });
  tintTo(CONFIG.colors.d2);
}
function tintTo(hex) {
  if (!logo.top) return;
  const c = new THREE.Color(hex);
  gsap.to(logo.top.material.color, { r: c.r, g: c.g, b: c.b, duration: 0.3, ease: 'expo.out' });
}

/* The source effect snaps to multiples of PI (half turns). Its mark is mirror-symmetric, so a half turn
   lands on an identical-looking pose. This monogram is not: at odd multiples of PI it rests
   back-to-front (a mirrored "LE"). Snap to full turns instead so every resting pose faces the
   viewer. The free scroll spin, the top/bottom desync and the snap itself are untouched. */
const TURN = Math.PI * 2;

function handleRotation(dt) {
  logo.scrollValue += logo.velocity * CONFIG.rotSpeed * logo.mouseFactor;
  let snap;
  if (logo.direction === 1) {
    snap = logo.mouseFactor ? Math.ceil(logo.scrollValue / TURN) * TURN
                            : Math.round(logo.scrollValue / TURN) * TURN;
  } else {
    snap = Math.floor(logo.scrollValue / TURN) * TURN;
  }
  if (logo.isScrolling && logo.state === '3D') {
    logo.target = logo.scrollValue;
  } else {
    logo.target = damp(logo.target, snap, CONFIG.lerpSnap, dt);
    logo.scrollValue = damp(logo.scrollValue, snap, CONFIG.lerpSnap, dt);
  }
  logo.rotA = damp(logo.rotA, logo.target, CONFIG.lerpTop, dt);
  logo.rotB = damp(logo.rotB, logo.target, CONFIG.lerpBottom, dt);
  if (logo.top)    logo.top.rotation.y = logo.rotA;
  if (logo.bottom) logo.bottom.rotation.y = logo.rotB;
}

/* reuse the glitch section's Lenis — no second scroll engine, no extra raf. */
if (lenis) lenis.on('scroll', (e) => {
  logo.velocity = e.velocity; logo.direction = e.direction || 1;
  logo.isScrolling = e.isScrolling; logo.progress = e.progress;
});

const pointer = { x: 0 };
window.addEventListener('pointermove', (ev) => { pointer.x = (ev.clientX / window.innerWidth) * 2 - 1; });

let last = performance.now();
function frame(now) {
  const dt = Math.min(now - last, 50); last = now;   // Lenis.raf is driven by the glitch gsap.ticker
  if (logo.ready) {
    handleRotation(dt);
    (logo.progress > CONFIG.threeDThreshold) ? set3D() : set2D();
    logo.mouseRotY = pointer.x * CONFIG.mouseAmp;
    logo.base.rotation.y = damp(logo.base.rotation.y, logo.mouseRotY, CONFIG.mouseLerp, dt) * logo.mouseInfluence;
  }
  renderer.render(scene, camera);
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
</script>

<!--
  Header-nav hover effect, ported 1:1.

  ORIGINAL (Webflow IX2):
    DOM: a.global-block-link (height:1rem; overflow:hidden)
           > .globa-block-link-track (flex column)
               > .global-nav-link  (copy 1)
               > .global-nav-link  (copy 2, identical clone)
    Trigger i-2f9aa434 (hover "each"):  mouseenter -> play,  mouseleave -> reverse
    Timeline t-3fa2086d, target = .globa-block-link-track, splitText:{type:"chars"}:
        wf:transform y: ["0%","-19px"]   (one line-height; reveals the clone)
        duration 0.6, stagger {each:0.03}, ease 9
    Webflow EASING_NAMES[9] === "power3.inOut"   (verified from webflow runtime chunk)

  This port rebuilds the same idea generically: each character becomes its own
  overflow-hidden mask holding the letter twice (original + clone) stacked, and on
  hover every char's inner rolls up exactly one line-height with a 0.03 left-to-right
  stagger. Uses window.gsap (play/reverse timeline == Webflow's play/reverse) when
  present, else falls back to CSS transitions with per-char transition-delay.
-->
<style>
  /* nav hover -- all classes prefixed dh- ; no global/body rules */
  .dh-link{
    display:inline-flex;
    align-items:flex-start;
    white-space:pre;            /* keep exact spacing of the label */
    cursor:pointer;
  }
  .dh-char{
    display:inline-block;
    overflow:hidden;
    height:1.2em;               /* ~ the 19px @16px line-height dash used */
    line-height:1.2;

  }

    will-change:transform;
  }
  .dh-face{
    display:block;
    line-height:1.2;
  }
  /* CSS-only fallback (used when window.gsap is absent). Per-char delay is set
     inline at build time so the stagger survives without JS driving each frame. */
  .dh-link.dh-css .dh-char-inner{
    transition:transform .6s cubic-bezier(.645,.045,.355,1); /* approx power3.inOut */
  }

<script>
(function(){
  "use strict";
  var DUR = 0.6, STAGGER = 0.03, EASE = "power3.inOut"; // source values

  function buildChars(el){
    var text = el.textContent;               // preserve label EXACTLY (counts/spaces)
    el.textContent = "";
    for(var i=0;i<text.length;i++){
      var ch = text[i];
      var display = (ch === " ") ? " " : ch; // keep width of spaces
      var charEl = document.createElement("span");
      charEl.className = "dh-char";
      var inner = document.createElement("span");
      inner.className = "dh-char-inner";
      var f1 = document.createElement("span"); f1.className = "dh-face"; f1.textContent = display;
      var f2 = document.createElement("span"); f2.className = "dh-face"; f2.textContent = display;
      inner.appendChild(f1); inner.appendChild(f2);
      charEl.appendChild(inner);
      el.appendChild(charEl);
    }
    return el.querySelectorAll(".dh-char-inner");
  }

  function attachOne(el){
    if(!el || el.getAttribute("data-dh-init") === "1") return; // idempotent
    if(!el.textContent.length){ return; }
    el.setAttribute("data-dh-init","1");
    el.classList.add("dh-link");

    var inners = buildChars(el);
    var gsap = window.gsap;

    if(gsap && typeof gsap.timeline === "function"){
      var tl = gsap.timeline({paused:true});
      tl.to(inners, {                 // roll up one line-height -> reveal clone
        yPercent:-50,                 // inner holds 2 faces; -50% == 1 face == 1 line
        duration:DUR,
        ease:EASE,
        stagger:STAGGER               // left-to-right, matches Webflow char split
      });
      el.addEventListener("mouseenter", function(){ tl.play(); });   // Webflow: play
      el.addEventListener("mouseleave", function(){ tl.reverse(); });// Webflow: reverse
    } else {
      // Pure-CSS fallback: bake the stagger as per-char transition-delay.
      el.classList.add("dh-css");
      for(var i=0;i<inners.length;i++){
        inners[i].style.transitionDelay = (i*STAGGER) + "s";
      }
      el.addEventListener("mouseenter", function(){ el.classList.add("dh-hover"); });
      el.addEventListener("mouseleave", function(){ el.classList.remove("dh-hover"); });
    }
  }

  function attach(selector){
    try{
      var nodes = (typeof selector === "string")
        ? document.querySelectorAll(selector)
        : selector;
      if(!nodes) return;
      if(nodes.nodeType) nodes = [nodes];
      Array.prototype.forEach.call(nodes, attachOne);
    }catch(e){ /* never throw */ }
  }

  window.dashHover = { attach: attach };
})();
</script>

import * as THREE from 'three';
import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
const gsap = window.gsap;
const canvas = document.getElementById('lf-copyright-canvas');
if (canvas) {
  const renderer = new THREE.WebGLRenderer({ canvas, alpha:true, antialias:true, powerPreference:'high-performance' });

  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(55, 1, 0.1, 100);
  camera.position.set(0,0,3.5); camera.lookAt(0,0,0);
  scene.add(new THREE.AmbientLight(0xffffff, 1));

  function resize(){ const w=canvas.clientWidth||120, h=canvas.clientHeight||120;
    renderer.setPixelRatio(Math.min(Math.max(window.devicePixelRatio,1),2));
    renderer.setSize(w,h,false); camera.aspect=w/h; camera.updateProjectionMatrix(); }
  window.addEventListener('resize', resize); resize();

  const group = new THREE.Group(); group.rotation.x = 0.15; scene.add(group);

  let envMap = null; const pmrem = new THREE.PMREMGenerator(renderer);
  new THREE.TextureLoader().load('https://qclay.design/lovable/nothin/env.webp', (tex)=>{
    tex.mapping = THREE.EquirectangularReflectionMapping; tex.colorSpace = THREE.SRGBColorSpace;
    envMap = pmrem.fromEquirectangular(tex).texture; scene.environment = envMap;
    if (group.userData.mat){ group.userData.mat.envMap = envMap; group.userData.mat.needsUpdate = true; }
    tex.dispose();
  });

  let ready=false, rotY=0, angVel=-0.6;   // spins to the right (around Y)
  const IDLE=-0.6, DRAG_SENS=0.012, FLICK_MAX=26; // idle rad/s (rightward), drag rad/px, max flick

  new GLTFLoader().load('https://qclay.design/lovable/nothin/copyright.glb', (gltf)=>{
    let src=null; gltf.scene.traverse(o=>{ if(o.isMesh && !src) src=o; });
    const geo=src.geometry.clone(); geo.computeBoundingBox();
    const c=new THREE.Vector3(), s=new THREE.Vector3();
    geo.boundingBox.getCenter(c); geo.boundingBox.getSize(s);
    const sc=2.6/Math.max(s.x,s.y,s.z);
    geo.translate(-c.x,-c.y,-c.z); geo.scale(sc,sc,sc);
    const mat=src.material; mat.envMap=envMap; mat.envMapIntensity=1.4;
    mat.color=new THREE.Color('#EEECEA'); mat.needsUpdate=true;
    group.userData.mat=mat; group.add(new THREE.Mesh(geo, mat));
    ready=true;
    if (gsap) gsap.from(group.scale, { x:0, y:0, z:0, duration:1, ease:'expo.out' });
  });

  // ── flick-to-spin ──
  let dragging=false, lastX=0, lastT=0, vel=0;
  const now=()=>performance.now();
  canvas.addEventListener('pointerdown', (e)=>{ dragging=true; lastX=e.clientX; lastT=now(); vel=0; angVel=0;
    try{ canvas.setPointerCapture(e.pointerId); }catch(_){} });
  canvas.addEventListener('pointermove', (e)=>{ if(!dragging) return; const t=now();
    const dx=e.clientX-lastX; const dt=Math.max(t-lastT,1);
    rotY += dx*DRAG_SENS; vel = (dx*DRAG_SENS)/dt; lastX=e.clientX; lastT=t; });
  const release=()=>{ if(!dragging) return; dragging=false;

  canvas.addEventListener('pointerup', release);

      group.rotation.y = rotY;
    }
    renderer.render(scene, camera); requestAnimationFrame(frame);
  }
  requestAnimationFrame(frame);
}
