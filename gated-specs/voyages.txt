Build "Voyages & Chapters" — an editorial small-group travel studio landing page. Vite +
React 18 + TypeScript + Tailwind CSS + Motion (Framer Motion's successor package,
imported from 'motion/react'). Ten sections, driven by three real interaction mechanisms:
scroll-linked parallax (useScroll/useTransform), reveal-on-view line/word animation
(useInView + custom split components), and a cursor-tracked circular image-reveal lens.

===============================================================================
STACK & FILES
===============================================================================
Vite + React + TypeScript + Tailwind (Tailwind v4 @theme syntax in CSS, not tailwind.config
theme.extend). Path alias '@' -> './src'. Dependencies: motion, lucide-react,
@supabase/supabase-js (present, unused on the page). cn()-style helpers not used — plain
template strings for conditional classes throughout.

Files: src/main.tsx, src/App.tsx, src/index.css, and one component per section under
src/components/, plus two shared primitives (AnimatedWords, AnimatedLines, PixelButton)
reused across sections.

App.tsx renders, inside a div with bg-[#f8f3ef] text-[#1a1a1a] font-sans antialiased
overflow-x-hidden: Header, then <main> holding Hero, Story, Lens, UpcomingTours,
TravelIntention, WhyTravel, FeaturedTour, TravelerStories, Faq, ClosingCta — then Footer
outside <main>.

SHARED PRIMITIVES
===============================================================================
AnimatedWords.tsx — splits text on spaces; each word is an overflow-hidden span containing
a motion.span that animates from {y:'100%',opacity:0} to {y:'0%',opacity:1}, staggered
`baseDelay + i*stagger` per word (defaults duration .5, stagger .07). Takes an isInView
prop from the caller rather than measuring itself — used where the parent already has an
useInView.

AnimatedLines.tsx — the line-reveal building block, used for every section headline.
Splits text on spaces, then MEASURES actual line-wrapping in a hidden mirror div (spans
with data-word, grouped by matching offsetTop) so the animation staggers by real rendered
line, not by a guessed word count — re-measures once document.fonts.ready resolves, so a
FOUT reflow can't leave stale line groups. Each measured line is wrapped in an
overflow-hidden div and animates the same {y:'100%'->'0%', opacity:0->1} as AnimatedWords,
staggered `baseDelay + i*stagger` per LINE, driven by a local useInView (once:true,
threshold=`amount`, default 0.4). Props: duration (.42), stagger (.06), baseDelay (0),
amount (.4), targetOpacity (1), firstLineIndent, forceSingleLine (skips all measurement).

PixelButton.tsx — a canvas-based hover-fill effect, the page's signature button treatment.
An absolutely-positioned <canvas> sits behind the button label inside a relative/isolate
anchor. On pointerenter it animates a 0->1 "fill progress" (rAF loop, speed-controlled
duration, default .45s); on pointerleave it reverses. Each animation frame redraws a grid
of `pixelSize`px squares (default 5-6px) across the button, filling in the ones whose
precomputed per-cell threshold is below the current progress. Thresholds are NOT random —
`thresholds[i] = ((x / (cols-1)) * 0.65 + hash(i) * 0.35) * 0.92`, a deterministic hash
function seeded by cell index, blended 65% left-to-right sweep + 35% noise, so the fill
reads as a wipe from the left with a dissolved, static-like edge rather than a flat curtain
or fully random scatter. Cells within 0.12 of the threshold render at 45% alpha for one
extra frame (a soft leading edge). Text color and border color crossfade via CSS transition
once fill progress passes 0.6. Config props: pixelColor, pixelSize, speed, textColor,
hoverTextColor, hoverBorderColor.

2. HERO (src/components/Hero.tsx)
===============================================================================
h-screen min-h-[700px], useScroll({target:ref, offset:['start start','end start']}) drives
three transforms as the hero scrolls past: the background image translates y 0%->25%
(useTransform), a black overlay's opacity rises .35->.6 over the first half of scroll, and
the foreground content column both translates y 0%->40% AND fades opacity 1->0 over the
first 60% — so the hero image parallaxes slower than scroll while the copy visibly sinks
and dissolves as you leave, a genuine two-speed scroll effect, not a single parallax layer.
  heroImage: https://images.pexels.com/photos/14036107/pexels-photo-14036107.jpeg?auto=compress&cs=tinysrgb&w=1920

Content (centered): eyebrow "Curated Journeys — Est. 2016" (font-mono, fades/rises in at
delay .3s), then the headline via AnimatedLines: "Voyages crafted with a story." at
text-[12vw] down to lg:text-[6.5vw], baseDelay .6 stagger .12 duration .7 amount .2 — this
is the single largest, slowest reveal on the page and the first thing a visitor reads.

unhurried, and personal. Not itineraries. Stories you step into." Two CTAs at delay 1.7s:
"Explore Upcoming Journeys" (solid white pill) -> #journeys, "Plan Your Own" (outline) ->

4. LENS (src/components/Lens.tsx) — "02 — The Lens" — SIGNATURE INTERACTION
===============================================================================
Dark section (bg-[#1a1a1a]). Left (5 cols, white text): eyebrow, h2 "Look closer. / Travel
deeper." (second line at 40% white opacity), body copy about layers within a single vista,
then "DRAG TO EXPLORE" beside a thin horizontal rule.
Right (7 cols): a 4:3 rounded-2xl image stage. useScroll({target, offset:['start end','end
start']}) drives the BASE image's scale 1.1->1->1.05 as the section crosses the viewport
(a gentle scroll-driven zoom, independent of the hover interaction below).
  base image (mountain vista):  https://images.pexels.com/photos/16970043/pexels-photo-16970043.jpeg?auto=compress&cs=tinysrgb&w=1600
  inner image (road detail):    https://images.pexels.com/photos/6130817/pexels-photo-6130817.jpeg?auto=compress&cs=tinysrgb&w=1200
On mousemove within the stage, track pointer position as a percentage of the element's
bounding rect (pos.x, pos.y). A second, absolutely-stacked image (the "inner" image) is
masked with `clip-path: circle(20% at ${pos.x}% ${pos.y}%)` and its opacity springs to 1 on
mouseenter / 0 on mouseleave (.3s) — so a 20%-radius circular window follows the cursor and
reveals the second photograph through the first, with a 96px white-ringed circle outline
drawn at the cursor position for a lens-like frame. cursor:none on the stage (the circle
itself is the cursor). While inactive, a centered "HOVER TO REVEAL" pill (dark glass, mono
caps) sits over the image and fades out the moment the lens activates.

RESPONSIVE
===============================================================================
Tailwind default breakpoints (sm/md/lg), no custom values. Nav collapses to a hamburger
dropdown below md. Every "N-col grid + sticky left column" layout (Story, Faq) drops the
sticky behavior and stacks single-column below lg since Tailwind's lg:col-span/lg:sticky
utilities simply don't apply. Card grids step 4→2→1 columns at lg/sm. Hero and ClosingCta
headline sizes are already fluid (vw-based clamps via Tailwind's text-[Nvw] arbitrary
values), so they don't need discrete breakpoint overrides.

===============================================================================
ACCEPTANCE
===============================================================================
- Every AnimatedLines/AnimatedWords instance fires once on first intersection and never
  re-fires on scroll-back (useInView once:true throughout).
- AnimatedLines measures real rendered line breaks (via the hidden mirror + data-word
  spans), not a word-count guess — resize the viewport and headlines should still wrap
  and stagger correctly.
- The Lens section's circular reveal tracks the cursor smoothly with no lag, respects the
  stage's actual bounding rect at any viewport width, and the "HOVER TO REVEAL" pill fades
  out exactly when the lens activates.
- PixelButton's fill sweeps left-to-right with a dissolved (not hard) edge, reverses
  cleanly on pointerleave even mid-animation, and its canvas resizes correctly on container
  resize (ResizeObserver-driven, not measured once on mount).
- Hero's image, overlay and content all move at visibly different rates while scrolling
  through the hero (three independent useTransform outputs from one useScroll).
- Zero console errors; zero horizontal overflow at any breakpoint.
- FONT LICENSING: before shipping anywhere public, replace 'Behind The Nineties' with a
  licensed or open-source equivalent and drop 'Noi Variable Flex Trial' entirely (it is
  unused in practice — everything using --font-noi already renders in the Inter Tight
  fallback). Re-host or replace the fifteen Pexels-hotlinked images and the qclay.design
  favicon before treating this as a finished, ownable asset.
