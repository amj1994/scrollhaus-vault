## 12. JavaScript — seven small IIFEs, no libraries
1. Entry-animation cleanup: add .anim-done on animationend, guarding e.target === el.
2. Nav controller: one setOpen(open) that early-returns if unchanged, toggles .is-open / .is-active, sets aria-expanded and swaps aria-label between "Close menu" and "Open menu", toggles .nav-lock on BOTH documentElement and body, focuses the first link after 360ms with preventScroll, and returns focus to the hamburger on close. Escape closes; Tab is trapped by cycling first/last of a[href],button.
3. Scroll reveal: one IntersectionObserver, rootMargin '0px 0px -12% 0px', threshold .15, watching .reveal,.step,.tstep,.hour; adds .is-in and unobserves. Under prefers-reduced-motion it adds .is-in to everything immediately and writes the final counter values.
4. Timeline rail: on a passive scroll listener behind requestAnimationFrame, set .timeline__prog height to clamp((innerHeight*0.62 - railTop) / railHeight, 0, 1).
5. Background video gating: an IntersectionObserver plays the integrative video only while it is on screen and pauses it otherwise, flipping preload to auto on first intersection.
6. Payer marquee: clone every item once with aria-hidden="true" and blank alt, then start the marquee animation from JS so a no-JS or reduced-motion visitor sees one static set instead of a half-empty strip.
7. Forms: preventDefault, honeypot check, then validate [required] — checkbox by checked, everything else by trimmed value plus checkValidity. Mark failures with a var(--alert) border, focus the first one, and on success hide the form and reveal a role="status" confirmation.

## 16. Scars — things that cost real time here
- A bare .brand{display:flex} written for the topbar silently destroyed the footer brand column. Scope it as .topbar .brand.
- overflow-x:hidden on body makes body a scroll container; use overflow-x:clip on html and body.
- Verifying in a hidden browser pane or a zero-width emulated viewport returns garbage. Assert window.innerWidth before trusting any measurement, and cache-bust the URL, because a stale cached stylesheet will make a correct fix look broken.
- Headless Chrome will not advance a <video> while you screenshot it. To capture this page frame by frame, extract the clip with ffmpeg, swap each <video> for an <img> with the same classes, and set img.src per frame with await img.decode() before each shot.
